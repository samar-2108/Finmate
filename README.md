# 🚀 Finmate (Project Setup Guide)

## 📌 Project Structure

```
project/
  frontend/   # React app
  backend/    # Fastapi backend
```

---

## 🧑‍💻 For New Contributors (IMPORTANT)

### 1. Clone the Repository

```bash
git clone https://github.com/samar-2108/Finmate.git
cd Finmate
```

---

### 2. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

---

### 3. Setup Backend

```bash
cd backend
npm install
npm run dev
```

---

## 🔄 Daily Workflow (Follow this ALWAYS)

### Before starting work:

```bash
git pull origin main
```

---

### After making changes:

```bash
git add .
git commit -m "your message"
git push origin main
```

---

## 🌿 Branching (Recommended)

Create your own branch:

```bash
git checkout -b feature-name
```

Push:

```bash
git push origin feature-name
```

Then create Pull Request on GitHub.

---

## ⚠️ Rules

* ❌ Do NOT push node_modules
* ❌ Do NOT push .env file
* ✅ Always pull before working
* ✅ Write clear commit messages
